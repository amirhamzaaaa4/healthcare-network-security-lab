# Configuration examples

These text files are **illustrative starting points**, not exported running configurations and not proof of implementation. Cisco syntax and supported features vary by Packet Tracer device and IOS image. Adapt interface names, verify commands, and remove secrets before committing any real output.

- `switch-example.txt`: VLANs, access ports, trunk, and basic hardening placeholders.
- `router-example.txt`: router-on-a-stick gateways and conceptual ACL examples.

Never store real passwords, password hashes, SNMP communities, private keys, tokens, or production addresses here.
